# 📊 Campaign Management System

## 📝 Introduction  
The **Campaign Management System** is a **data-driven marketing analytics platform** that enables businesses to **track, analyze, and optimize** their marketing campaigns.  

This project integrates:
- **SQL Server** as the database  
- **CSV files** as the data sources  
- **Power BI** for interactive dashboards and analytics  

By leveraging these technologies, the system enhances **decision-making**, improves **marketing ROI**, and provides **real-time insights** into customer behavior and campaign performance.  

---

## 📂 Data Sources  
The system relies on **CSV files** containing marketing data, which are processed and loaded into **SQL Server** for structured analysis.

### 🔹 **CSV Files Used**
| File Name               | Description |
|-------------------------|-------------|
| `campaign_data.csv`     | Marketing campaign details |
| `customer_info.csv`     | Customer demographics and spending |
| `customer_activity.csv` | Web visits, purchases, and interactions |
| `marketing_response.csv`| Customer engagement with campaigns |

---

## 📊 Power BI Dashboards  

### 📈 **Campaign Performance Dashboard**  
- Tracks **Impressions, Clicks, CPC, ROI, and Customer Acquisition Cost (CAC)**  
- Helps identify **high-performing and low-performing campaigns**.  

---

### 🛍 **Customer Behavior Analysis Dashboard**  
- Analyzes **customer purchases** from different channels (web, store, catalog).  
- Segments customers based on their **buying patterns**.  

---

### 📊 **Customer Overview Dashboard**  
- Provides **insights into demographics** like income, marital status, education.  
- Helps businesses **optimize marketing targeting**.  

---
